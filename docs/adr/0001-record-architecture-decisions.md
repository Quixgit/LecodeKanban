# 0001 — Record architecture decisions

- Status: accepted
- Date: 2026-10-01

## Context

The brief asks for sensible decisions to be made without blocking and recorded in `docs/adr/`.

## Decision

We use lightweight ADRs (Michael Nygard format): one numbered Markdown file per decision with
Context / Decision / Consequences. ADRs are immutable once accepted; a change of mind is a new ADR
that supersedes the old one.

## Consequences

Reviewers can trace why the codebase looks the way it does without reading chat history.
